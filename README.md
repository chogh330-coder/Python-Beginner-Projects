# 가위바위보 3판 2선승 게임

## 프로젝트 소개
Python으로 제작한 콘솔 기반 가위바위보 게임입니다.

컴퓨터와 가위바위보 대결을 진행하며, 먼저 2점을 획득하면 승리합니다.

## 주요 기능
- 가위, 바위, 보 선택
- 컴퓨터의 무작위 선택
- 승패 판정 및 점수 누적
- 3판 2선승제
- 게임 재시작 및 종료
- 현재 점수 확인
- 잘못된 입력 처리

## 사용 기술
- Python
- random 모듈
- time 모듈

## 제작 목적
Python의 조건문, 반복문, 변수 및 기본 모듈 사용법을 익히기 위해 제작했습니다.
