# 프로젝트 1: 가위바위보 3판 2선승 게임

## 프로젝트 소개
Python으로 제작한 콘솔 기반 가위바위보 게임입니다.
컴퓨터와 가위바위보 대결을 진행하며, 먼저 2점을 획득하면 승리합니다.

## 주요 기능
- 가위, 바위, 보 선택
- 컴퓨터의 무작위 선택
- 승패 판정 및 점수 누적
- 3판 2선승제
- 게임 재시작 및 종료
- 현재 점수 확인
- 잘못된 입력 처리

## 사용 기술
- Python
- random 모듈
- time 모듈

## 제작 목적
Python의 조건문, 반복문, 변수 및 기본 모듈 사용법을 익히기 위해 제작했습니다.

# 프로젝트 3: 숫자 추리 게임

## 프로젝트 소개
Python으로 제작한 콘솔 기반 숫자 추리 게임입니다.
컴퓨터가 생성한 세 자리 숫자를 추리하며, 입력한 숫자와 정답을 비교해 정위치, 위치 오류, 불일치 결과를 확인할 수 있습니다.

## 주요 기능
- 0~9 사이의 중복 없는 세 자리 숫자 생성
- 첫 번째 자리 숫자 0 제한
- 입력한 숫자와 정답 비교
- 정위치, 위치 오류, 불일치 판정
- 정답을 맞히면 승리
- 게임 규칙 안내
- 게임 재시작 및 종료

## 사용 기술
- Python
- random 모듈
- 리스트(List)
- 조건문 및 반복문

## 제작 목적
Python의 중첩 반복문과 조건문을 활용한 게임 진행 구조를 익히고, 리스트와 자료형 변환을 이용한 데이터 처리 및 비교 방법을 연습하기 위해 제작했습니다.

# 프로젝트 4: 자판기 시뮬레이터

## 프로젝트 소개
Python으로 제작한 콘솔 기반 음료 자판기 시뮬레이터입니다.
사용자가 금액을 투입하고 원하는 음료를 선택하면 구매를 진행하며, 금액이 부족할 경우 추가 투입 또는 구매 취소를 선택할 수 있습니다.
Python 기초 문법을 활용하여 자판기의 기본적인 구매 과정을 구현해 보았습니다.

## 주요 기능
- 음료 메뉴 및 가격 출력
- 금액 투입 및 음료 선택
- 금액 부족 시 추가 투입
- 구매 취소 및 투입 금액 반환
- 거스름돈 계산
- 재구매 및 프로그램 종료

## 사용 기술
- Python
- 조건문 (`if`, `elif`, `else`)
- 반복문 (`while`, `break`, `continue`)
- 딕셔너리 (`dict`)
- 사용자 입력 (`input`)
- 문자열 포매팅 (f-string)

## 학습 목표
Python의 기초 문법을 활용하여 사용자 입력에 따른 프로그램의 흐름을 제어하고, 간단한 자판기 구매 시스템을 구현하는 것을 목표로 합니다.
