# 프로젝트 1: 가위바위보 3판 2선승 게임

## 프로젝트 소개
Python으로 제작한 콘솔 기반 가위바위보 게임입니다.

컴퓨터와 가위바위보 대결을 진행하며, 먼저 2점을 획득하면 승리합니다.

## 주요 기능
- 가위, 바위, 보 선택
- 컴퓨터의 무작위 선택
- 승패 판정 및 점수 누적
- 3판 2선승제
- 게임 재시작 및 종료
- 현재 점수 확인
- 잘못된 입력 처리

## 사용 기술
- Python
- random 모듈
- time 모듈

## 제작 목적
Python의 조건문, 반복문, 변수 및 기본 모듈 사용법을 익히기 위해 제작했습니다.

# 프로젝트 2: 업다운 게임

## 프로젝트 소개
Python의 반복문과 조건문을 활용하여 제작한 숫자 맞히기 게임입니다.

## 주요 기능
- 1~100 사이의 랜덤 숫자 생성
- 입력한 숫자에 따라 UP / DOWN 안내
- 최대 10번의 기회 제공
- 정답 및 실패 처리
- 게임 재시작 및 종료 기능

## 사용 기술
- Python
- random
- time

## 제작 목적
Python의 조건문과 반복문을 활용하고, 게임의 진행 상황에 따라 반복문을 제어하는 방법을 익히기 위해 제작했습니다.
